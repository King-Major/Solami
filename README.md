# Solami Website Redesign (Proposal)

A modern, mobile-first web interface proposed for Solami. This redesign shifts away from traditional horizontal corporate layouts, embracing a high-end "Bento Box" architecture to showcase Solami's API and communication infrastructure. 

## 🎯 Project Vision

The goal of this redesign is to visually position Solami as a premium, developer-first technology company. The design language communicates stability, modernity, and ease of use.

### Key Design Pillars
* **Mobile-First Architecture:** The layout prioritizes touch targets, readable typography, and smooth vertical scrolling on mobile devices before expanding into an asymmetrical grid on desktop screens.
* **Bento Box UI:** Content is organized into modular, rounded cards. This makes dense information (like API capabilities and telecom solutions) digestible and visually engaging.
* **High Contrast:** Pristine white backgrounds paired with deep slate text and strategic uses of "Solami Teal" and gold accents guide the user's eye to high-value actions (CTAs).
* **Developer-Centric:** The inclusion of dark-mode IDE snippets directly in the hero and developer sections signals immediately that Solami is built for engineers.

## 🛠 Tech Stack

This project is lightweight and blazing fast, utilizing the modern React ecosystem:
* **Framework:** [React](https://react.dev/) via [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Zero-config setup)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Typography:** System Sans-Serif (Primary) and System Mono (Code Snippets)
